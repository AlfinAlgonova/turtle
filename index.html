📚 Quick Review Sebelum Mulai

Selamat datang! Sebelum menyelesaikan 10 challenge, mari kita ingat kembali 4 konsep utama Python Turtle yang akan kamu gunakan:

🔄 1. FOR (Perulangan)

Digunakan untuk mengulang perintah agar tidak perlu menuliskan kode yang sama berulang kali.

for i in range(4): forward(100) right(90)

🔀 2. IF ELSE (Kondisi)

Digunakan untuk membuat keputusan. Program akan memilih apa yang harus digambar berdasarkan nilai variabel.

if waktu == "siang": color("yellow") else: color("gray")

📦 3. DEF (Membuat Function)

Digunakan untuk membungkus sekumpulan perintah gambar menjadi satu nama khusus.

def buat_kotak(): for i in range(4): forward(100) right(90)

🚀 4. Memanggil Function

Menuliskan def saja tidak akan menggambar apa-apa. Kamu harus memanggilnya!

buat_kotak() # <--- Memanggil function
